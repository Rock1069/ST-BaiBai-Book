# 写实推演模式（v1.2.15）

## 入口

柏宝书 → **剧情推进** → 「正文生成前自动推演」下方的 **写实推演模式**。默认关闭，每个聊天独立保存；刷新或切换聊天后恢复该聊天的设置。

打开后，点击「生成推进建议」即可手动使用；开启自动推演则对新的用户消息使用。无需导入整本《写实世界》即可获得内置检查。

## 检查内容

- 角色认知是否有信息来源，区分自述、传闻、推测与确证，避免读心和全知。
- 人物行动是否符合人格、目标、关系历史、利益、顾虑和环境，保留 NPC 自身事务与用户决定权。
- 事件是否有触发、行动条件和合理后果，信息传播是否有路径，冲突升级是否有新依据。
- 尚未结算的行动是否符合已知能力、资源和世界机制，考虑限制、代价及不同结果，不默认必胜或强制失败。
- 好感、信任、能力认可、合作与服从是否被混写，关系转变是否有历史与新依据。
- 原著基准明确时保持连续，偏离应有可追溯原因；魔法、仙侠等沿用各自世界规则，不强行套现实限制。

规则提炼了《写实世界》的因果、认知、人物决策和关系连续性思路，采用独立的推演提示。没有加入其叙述视角、文风或身体交互要求。模式不会新建角色动机档案或关系字段；这些检查作用于本次推演建议。

## 请求与输出

检查直接合并到现有推演 API 请求，**不会新增检查请求**；使用第三方多阶段预设时，每个原有阶段附带检查，任务数量和次序保持现状。内置和自定义推演同样支持。

保留原有输出格式、标签及末尾 assistant 预填充。检索阶段只核对已发生事实，未来建议仍标明尚未发生；与本轮相关的理由、条件、代价和不确定处融入原有建议，再通过原有采用流程交给正文模型。模式不要求输出额外检查报告，也不增加正文文风指令。模型的实际采纳仍取决于本次生成。

**摘要、总结及事实记账继续使用柏宝书现有方法。** 写实规则只发送给剧情推演，不注入摘要任务，也不直接写入角色、物品或记忆台账。若用户另外在 SillyTavern 挂载原世界书，其激活与排除仍按原有世界书配置处理。

## 保存与已有推演

开关保存到聊天元数据 `bbs_plot.settings.realism`。内置配置另存为预设、导出当前预设时携带开关；选用带该设置的预设会恢复其值，没有该字段的旧预设沿用当前聊天选择。

开启或关闭只影响后续新推演，不自动取消或重做已有结果。AI 回复删除、重生成或切页继续复用对应用户楼的已采用推演；删除对应用户消息才使该计划失效。若要把当前旧建议改为写实建议，可手动生成一次后点击「下一次生成使用」替换。
