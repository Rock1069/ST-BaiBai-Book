# DEM × Stab’s · 场景导演

柏宝书 v1.2.23 新增第三套内置剧情推进提示词，借鉴 DEUS EX MACHINA V2.5 的场景、路线与线索设计，以及 Stab’s Directives V3.0.1 的人物行为和认知边界。中文规划提示词为柏宝书重新编写，属于适配方案，不是作者的官方联合预设。

## 使用

1. 更新柏宝书并刷新酒馆，打开「剧情推进」。
2. 「剧情推进预设」选择「柏宝书内置 / 自定义提示词」。
3. 「推演提示词」选择「内置三：DEM × Stab’s（场景导演）」。
4. 可点击「生成推进建议」手动使用，也可开启「正文生成前自动推演」。长期推进偏好、世界书选择和 API 继续沿用此聊天的配置。

无需逐条选择路线。已有聊天的预设选择保持原值；新选项影响之后生成的新推演，已绑定用户楼的旧推演仍按原结果复用。

## 规划内容

| 板块 | 内容 |
| --- | --- |
| 场景规划 | 核对时间、地点、在场人物和当前节奏 |
| 已发生的依据 | 本轮相关的最多三条事实，区分意图与完成的行动 |
| 候选路线 | 四条有条件的不同路线，允许平静方向和暂缓 |
| 选定情节点 | 自动选定唯一方向，条件不满足可自然延续 |
| 下一段行动 | 承接、NPC/环境变化、即时后果、用户回应处与退路 |
| 角色认知边界 | 角色所知、已有信息来源及缺少知情依据的秘密 |
| 剧情线索 | 本轮相关的既有主支线、承诺与伏笔；拟推进内容明确待确认 |
| 连续性约束 | 本轮须保持的时间/空间、状态、设定和用户行动权 |

所有规划在同一次模型调用中生成，输出约 600–1000 字，资料少时缩短。沿用内置的近期正文、相关摘要/总结检索与状态输入；模型可以遗漏或误解约束，仍可编辑推演后采用。

## 展示和正文执行

- 推演页和用户消息层继续使用现有折叠美化卡片，八个标题自动分节。
- 原始推演保留全部候选；识别到「选定情节点」与「下一段行动」时，提交给正文的内容移除「候选路线」一节，避免同时展开未选方向。
- 正文执行约束随草稿、历史记录与用户楼一起保存，切换模式、载入记录或重生成时仍复用原约束。「追加到聊天输入框」也保留约束并移除未选路线。只实现选定行动，条件失效则自然退回当前场景。
- 候选和选定规划均属于尚未发生的建议，不直接写入事实、认知、物品或计划台账；只有实际生成的正文走原有摘要记录流程。未选路线不能当作既有伏笔。
- 认知来源要求来自已发生正文；禁止补造门外偷听、别人转告等前情来解释泄密。摘要中的读者信息不会自动变成角色知识。

## 与原作的适配差异

原 DEM 的路线选择依赖酒馆宏与正则路由。此方案由推演模型根据用户意图、因果条件、人物认知和节奏自动择一，不依赖原作宏、随机路由、HTML 模板或额外模型调用。Stab’s 的认知与人物逻辑在规划中始终生效，不要求开启额外的「写实推演模式」。

可通过「导出当前预设」导出当前配置，或直接导入随项目提供的 [独立预设](presets/DEM-Stabs-场景导演.plot-preset.json)。独立文件使用一个 `plotTasks` 任务，带正文执行约束，无 assistant 预填充；资料缺少时按已有信息规划。导入方式按第三方预设流程执行，历史资料范围遵循该流程；内置方式使用相关记忆筛选。
