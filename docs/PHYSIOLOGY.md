# 生理档案（v1.2.12）

## 开启入口

柏宝书 → **角色** → 最上方 **生理档案** → 右侧 **＋** 或「选择角色并开启」。选择主角或已有 NPC。新角色先在名册添加；聊天需至少有一条有效正文摘要，手动登记才能挂到该楼保存。

## 三部分功能

- **生理档案**：绑定角色，性别／年龄沿用现有角色档案，不预设年龄。身体注意事项可手动填写；启用开关控制该人物全部生理结算，暂停保留档案与历史。
- **周期／孕期时间线**：周期默认 28 天、经期 5 天，可修改；第 1 天为经期开始。当前天数默认未知，需校准或由正文明确经期开始建立锚点。孕期跟踪单独开启，默认未登记怀孕，预计长度默认 280 天，可自定义。确认怀孕、分娩、孕期结束只由已发生正文明确事件或手动登记改变。孕期天数未知时不会猜测；达到预计天数不会自动分娩。孕期／产后暂停周期；明确恢复经期或手动校准后恢复。
- **身体需求**：饥饿、口渴、疲劳为 0–100 的 RP 刻度，越高需求越强。默认未知，可手动校准；每故事小时分别增加 4／6／3，最高 100。可关闭时间增长。进食、饮水、睡醒将对应需求设为 10；明显劳累增加疲劳 20，明确恢复减少疲劳 20。未知值在没有对应事件前保持未知。

阶段和需求是可校准的故事模拟规则，不是现实身体判断。预计阶段不会强迫剧情出现症状或事件。

## 时间如何推进

1. 每条正文完成摘要后，优先按可靠故事日期差推进所有启用的档案；不读取电脑时间。
2. 支持数值年月日及可选 `HH:mm`，如 `2026/9/30 10:00`、`天元历12年3月1日 10:00`；只有同一纪年前缀与同一时间精度才比较。数值日期使用公历月份长度；特殊架空历法请用手动校准。月份名、时辰、模糊时间、无效日期不猜。
3. 日期无法计算／没有变化时，摘要模型可从本轮明确的相对时长提取一次总时长，必须附连续逐字正文证据。没有可靠时长则停止自动推进。倒叙或跨纪年不会反向修改身体状态，只重新建立时间锚点。
4. 「手动推进时间」用于已发生但尚未结算的时长，作用于所有启用档案。可计算日期已有锚点时，相对／手动时长会被后续日期差抵扣，避免重复计时；缺失锚点或换纪年时不能推断未记录的间隔。
5. 同一楼内的身体事件按摘要中的顺序在该楼结束时间结算；长时间跨度的楼层可手动校准细节。时间线保留每角色最近 100 条身体事件、校准及阶段／日期推进记录。

## AI 如何读取与记录

- 复用柏宝书现有逐楼摘要请求，发送已开启档案作为本轮之前的只读基线，返回 `physiology` 身体事件与明确时长；不额外调用生理 API。内置摘要模板与自定义模板均会补充该协议。
- AI 无权创建档案、开启周期／孕期或自由改写需求数值。事件逐字证据必须来自本轮待摘要正文；未开启人物、不在原文中的证据、重大身体事件的猜测／计划及明确错配人物的证据会丢弃。只有证据直接给出相同数字天数时才采纳孕期天数，其他情况保持未知或手动校准。
- 主角生理状态遵循「主角」注入开关；NPC 生理状态遵循「场景＋NPC」开关，只发送主要角色或当前在场的已登记角色。私密身体档案不代表其他人物已知。仅摘要模式不向正文模型发送结构化生理状态。
- 剧情推进会通过现有当前状态读取生理档案；推演建议本身不会结算，只有后续真实正文进入摘要才结算。
- 原有批量补摘流程只记录摘要与时间，仍不提取任何结构化身体事件；如需补记进食、怀孕等，请逐楼摘要／重新摘要或手动登记。

## 保存、回退与查看

所有事实与手动操作都写入对应有效正文楼层 `extra.bbs_leaf.delta.physiology`，不使用另一套独立存储。重新计算、刷新页面不会重复累计。删除楼层、切换回复或标记番外时，该楼生理变化随之回退；取消番外／恢复原回复时按有效叶子重放。重新生成摘要时保留该叶子上的手动生理登记与校准。

角色改名会同步档案归属；名册移除角色后保留历史生理档案。带数据创建新对话会携带完整档案、时间抵扣与时间线。楼层摘要面板可查看并删除本楼生理操作；角色页可校准当前值。移除档案再开启得到新档案，移除操作仍可随楼层回退。

公开只读接口：`STBaiBaiBook.getSnapshot().physiology` 或 `query({ resource: 'physiology' })`，支持指定楼层前／后快照。
